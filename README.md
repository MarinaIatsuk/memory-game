Учебный проект в рамках курса **RS School (Fullstack Engineering)**
=================================================


Игра "Memory" 
16 карточек (8 пар). Всё DOM‑дерево генерируется через JavaScript (в исходном `index.html` в `body` только скрипты). Стили хранится в `css/style.css`.

Структура проекта
-----------------
```
memory-game/
├── index.html          # в <body> только теги <script>
├── assets/
│   └── favicon.svg
├── css/
│   └── style.css       # все стили приложения
└── js/
    ├── dom.js          # обёртки над document.createElement
    ├── deck.js         # набор эмодзи, колода и перемешивание
    ├── storage.js      # таблица лидеров в localStorage, формат даты
    ├── modal.js        # общий компонент модального окна
    ├── ui.js           # хедер, счётчики, поле, карточки, содержимое окон
    ├── game.js         # состояние и правила игры
    └── app.js          # точка входа: собирает страницу и стартует игру
```



Требования
-----------------------------------


- Генерация DOM (15) — выполнено ✔
  - Вся разметка создаётся через `createElement` в `js/dom.js`. В `index.html` в `body` только `<script>`.

- Начало игры (10) — выполнено ✔
  - При загрузке вызывается `startGame()` (см. `app.js`). Поле создаётся с 16 карточками, счётчики обнуляются.

- Перемешивание (5) — выполнено ✔
  - Колода формируется и перемешивается функцией `createDeck()` + `shuffleArray()` (Fisher–Yates).

- Выбор карточек (15) — выполнено ✔
  - Открытие двух карточек по очереди, совпадающие пары помечаются `isMatched`, повторные клики игнорируются.

- Несовпавшие пары (10) — выполнено ✔
  - Несовпавшие пары закрываются через 1000 мс (в массиве допуск 700–1500 мс; значение `MISMATCH_DELAY = 1000` соответствует требованию).
  - Пока две несовпавшие карточки открыты, поле блокируется (`isLocked`) — остальные карточки нельзя открыть.

- Счётчики (5) — выполнено ✔
  - `moves` увеличивается при открытии второй карточки, `pairsFound` при совпадении.

- Модальные окна (15) — выполнено ✔
  - Открытие модалки победы происходит по завершении (с задержкой, затем `showWinModal`).
  - Общий код модалок реализован в `modal.js` и используется для таблицы лидеров и модалки победы.
  - Модалки закрываются кнопкой, кликом по бекдропу и клавишей Escape (fallback поддерживает эти сценарии).
  - Замечание: в браузерах без поддержки `dialog.showModal()` используется fallback, который визуально затемняет фон и блокирует прокрутку (`body.is-modal-open`). В большинстве современных браузеров `dialog.showModal()` корректно делает фон неактивным; при желании можно дополнительно установить `inert` или отключать кнопки хедера при fallback, но это корректность UX‑улучшение, а не критическая ошибка.

- Таблица лидеров (10) — выполнено ✔
  - `storage.js` хранит топ-10 результатов в `localStorage`, сортирует по ходам/дате и отдаёт корректный список.
  - При отсутствии результатов показывается сообщение (см. `createLeaderboardContent`).

- Новая игра (15) — выполнено ✔
  - Кнопка `Новая игра` вызывает `restartGame()` → `startGame()` и отменяет таймеры (`cancelGameTimers()`). Результаты прошлых игр не удаляются.

- README (5) — выполнено ✔
